# AERIS Ambulance System — Open-Source React Base

This application is built as a standalone open-source web application.

## Frontend engine

- React
- Vite
- TypeScript
- React Router
- Tailwind CSS
- Leaflet / React Leaflet

## Local development

```bash
npm install
npm run dev
```

The development server runs on `http://localhost:3001`.

## Important

The current UI is preserved while the application foundation is being migrated. Backend and realtime services can be connected independently after this migration.
